# 스크립트 프로젝트 설계

2026-09-13. 스크립트를 파일 하나에서 **VS 프로젝트처럼** 여러 소스·리소스·참조를 가진 묶음으로 넓힌다. C# 부터.

## 정한 것 (사용자)

- 프로젝트 파일 **하나**가 목록을 든다(VS 의 csproj 처럼).
- DevExpress 그리드의 **트리 보기**로 폴더별 파일을 보이고, **더블 클릭하면 탭 편집기**에 연다.
- 리소스는 전부 - 이미지·데이터(json·csv·txt)·DLL 참조·사운드.
- 언어는 **C# 먼저**. 파이썬·JS 는 나중에 import 만.
- 화면은 **트리 + 탭**. 파일마다 중단점.

## 프로젝트 파일

`<폴더>\<이름>.mtsproj` (JSON, UTF-8). 기본 자리는 `%AppData%\Minguk.Tools\Scripts\<이름>\`.

```json
{
  "version": 1,
  "name": "사격장",
  "language": "CSharp",
  "entry": "main.csx",
  "items": [
    { "path": "main.csx",            "kind": "Source" },
    { "path": "공통/조준.csx",        "kind": "Source" },
    { "path": "Resources/적.png",     "kind": "Resource" },
    { "path": "Resources/설정.json",  "kind": "Resource" },
    { "path": "Libs/Helper.dll",      "kind": "Reference" }
  ],
  "folders": [ "공통", "Resources", "Libs" ]
}
```

- **경로는 프로젝트 폴더 기준 상대, `/` 로 적는다.** 폴더째 다른 PC 로 옮겨도 그대로 열린다.
- **목록이 프로젝트다**(VS 처럼) - 단 **폴더를 하위까지 지켜보다** 새로 생긴 파일·폴더는 목록에 넣고, 없어진 것은 뺀다(사용자 요청).
  이미 있던 파일을 "프로젝트에서 제외" 한 것은 다시 안 들어온다(알림은 생길 때만 온다). 무시: 프로젝트 파일, .git·.vs·bin·obj, 임시 파일.
  밖에서 지운 파일의 탭은 고친 것이 없으면 닫고, 있으면 남겨 알린다.
- **끌어다 놓기**: 탐색기의 폴더(또는 프로젝트 줄)에 파일·폴더를 놓으면 **그 폴더로 복사**하고 목록에 넣는다. 원본은 둔다.
  같은 이름이면 덮지 않고 뒤에 숫자를 붙인다.
- `folders` 는 빈 폴더도 트리에 남기려고 둔다.
- `kind` 는 이름으로 적는다(열거형 순서가 바뀌어도 뜻이 안 변하게 - SequenceStepKind 와 같은 규칙).

## 컴파일 (C#)

Roslyn 스크립팅은 제출(submission) 하나에 글 하나다. 여러 파일은 `#load` 로 잇는다.

- 시작 파일(`entry`)을 컴파일할 때 **앞에 다른 소스 파일의 `#load` 를 붙이고 `#line 1` 로 줄 번호를 되돌린다.**
  사람이 `#load` 를 적지 않아도 프로젝트의 소스가 다 들어간다.
- 옵션에 `FilePath`(시작 파일 경로)·`SourceResolver`(프로젝트 폴더)·`MetadataResolver`(프로젝트 폴더) 를 준다 -
  사람이 직접 적은 `#load "../공용.csx"`·`#r "Libs/x.dll"` 도 된다.
- `Reference` 항목은 `MetadataReference` 로 넣는다.
- 오류는 **파일과 줄**로 나온다(`ScriptError.File`). 편집기는 제 파일의 오류만 밑줄 긋는다.
- 시작 파일이 아닌 소스에는 함수·클래스를 둔다. 최상위 실행문도 되지만 `#load` 순서(목록 순서)대로 먼저 돈다.

## 완성·분류

작업 공간의 문서는 여전히 하나다. 여는 파일마다 **같은 `#load` 머리말을 붙인 글**을 넣고 오프셋을 머리말 길이만큼 옮긴다.
그러면 다른 파일에 만든 함수도 완성·색에 나온다. 자기 자신은 머리말에서 뺀다.

## 리소스 API (실시간 · C# 부터)

| 이름 | 한글 | 무엇 |
|---|---|---|
| `ResourcePath(name)` | `리소스경로` | 전체 경로. 없으면 멈추고 이유를 말한다 |
| `ResourceText(name)` | `리소스글` | UTF-8 글 |
| `ResourceBytes(name)` | `리소스바이트` | 바이트 |
| `PlaySound(name)` | `소리` | wav 재생 |

`name` 은 프로젝트 기준 경로(`Resources/적.png`) 또는 `Resources/` 아래 이름(`적.png`). API 를 늘리면 네 곳(표·파이썬·JS·xshd)을 같이 고친다.

## 화면

- 스크립트 화면 오른쪽 "스크립트 편집" 칸이 **프로젝트 트리 | 탭 편집기** 로 나뉜다.
- 트리: `GridControl` + `TreeListView`. 폴더·소스·리소스·참조 아이콘. 더블 클릭 = 열기. 오른쪽 메뉴 = 새 파일·새 폴더·기존 항목 추가·이름 바꾸기·목록에서 빼기·시작 파일로.
- 탭: 파일마다 `ScriptEditor`. 제목 옆 `*` = 저장 안 함. 모두 저장(Ctrl+Shift+S). 닫을 때 저장 안 한 것은 묻는다.
- 밖에서 고친 파일은 지금처럼 다시 읽는다(파일마다).
- 플레이 화면은 파일 대신 프로젝트(`.mtsproj`)도 고른다. 한 파일짜리 `.csx` 도 그대로 된다.

## Visual Studio 2026 처럼 (2026-09-13 추가 결정)

**모든 것을 Visual Studio 2026 과 DevExpress WPF 기준으로** - 배치·동작·컨트롤·메뉴·도구 모음·단축키.
(도중에 "VSC" 로 잘못 말했다가 "VS 2026" 으로 바로잡았다. VS Code 가 아니다. 코드 색도 VS 2026 화면에서 쟀다.)

- **큰 틀은 DockLayoutManager** 로 VS 의 도구 창 도킹을 만든다. 폼 모양 칸(영역 이름·자리 등)은 그 창 안에서 LayoutControl.

  ```
  ┌ 메뉴: 파일 편집 보기 프로젝트 디버그 Git 도구 ─────────────────────────────────┐
  ├ 도구 모음: 표준(새 프로젝트·열기·저장·모두 저장) │ 디버그(▶ 시작 F5·■ 중지·한 줄) │ 캡처 ┤
  ├────────────────────┬────────────────────────────────┬───────────────────────┤
  │ 미리보기(게임)      │ 문서 탭 [main.csx] [조준.csx*] │ 솔루션 탐색기 │ Git 변경 내용│
  │ (도구 창)           │ (DocumentGroup)                │ (도구 창, 탭으로 겹침)     │
  ├────────────────────┴────────────────────────────────┴───────────────────────┤
  │ 오류 목록 · 출력 · 호출 · 변수 · 영역 · 중단점 (아래 도구 창 탭, 자동 숨김 가능)       │
  ├──────────────────────────────────────────────────────────────────────────────┤
  │ 상태 표시줄: 준비 │                    줄 12 열 5 │ ⊗ 0 ⚠ 0 │ ↑0 ↓0 │ ⎇ main │ Interception │
  └──────────────────────────────────────────────────────────────────────────────┘
  ```

  - **도구 창**: 제목 표시줄의 핀(자동 숨김)·×(닫기), 끌어서 다른 자리에 붙이기·떼어 내기. 닫은 창은 **보기** 메뉴로 다시 연다.
  - **문서 탭**: 저장 안 한 것은 제목 뒤 `*`. 탭의 × · 가운데 클릭 · Ctrl+F4 로 닫는다. 탭 오른쪽 메뉴: 저장·닫기·다른 탭 모두 닫기·전체 경로 복사·파일 탐색기에서 열기.
  - **솔루션 탐색기**: 프로젝트 줄 굵게, 시작 파일 굵게. 오른쪽 메뉴: 추가(새 항목·기존 항목·새 폴더)·시작 파일로 설정·열기·파일 탐색기에서 폴더 열기·잘라내기/복사/붙여넣기·삭제·이름 바꾸기·프로젝트에서 제외.
  - **오류 목록**: GridControl(코드·설명·파일·줄). 더블 클릭하면 그 파일·줄로 간다.
  - 배치는 저장·복원하고 **창 > 창 레이아웃 다시 설정** 으로 되돌린다.
- **메뉴·도구 모음·상태 표시줄은 BarManager**(MainMenuControl·ToolBarControl·StatusBarControl). 메뉴 이름은 VS 를 따르고 이 앱에 뜻 있는 항목만 둔다.
- **단축키는 VS 2026 과 같게**: Ctrl+S 저장 · Ctrl+Shift+S 모두 저장 · Ctrl+Shift+N 새 프로젝트 · Ctrl+Shift+O 프로젝트 열기 · Ctrl+Shift+A 새 항목 ·
  Shift+Alt+A 기존 항목 · Ctrl+F4 문서 닫기 · F5 시작/계속 · Shift+F5 중지 · F10 한 줄 · F9 중단점 · F2 이름 바꾸기 · Delete 삭제 ·
  Ctrl+Alt+L 솔루션 탐색기 · Ctrl+\,E 오류 목록 · Ctrl+Alt+O 출력.
  **F9 는 VS 처럼 중단점이고, 비상 정지는 Pause 키로 옮긴다**(사용자 결정). 도는 동안만 전역으로 쥐는 것은 그대로다.
- **Delete 는 VS 처럼 파일을 지운다 - 단 휴지통으로**(되돌릴 수 있게, 묻고 나서). 파일을 남기고 목록에서만 빼는 것은
  오른쪽 메뉴 **프로젝트에서 제외**(사용자 결정).
- **참조 표시(CodeLens)** - VS 처럼 메서드·속성·필드·클래스·함수 선언 위에 흐린 글씨로 "참조 N개". 누르면 편집기 위에 뜨는 창에
  파일별 묶음(`경로 (개수)`)으로 `줄 : 코드 줄` 을 보이고, 찾은 낱말은 칠한다. 줄을 더블 클릭하면 그 파일·줄로 간다. 아래에 "모두 축소".
  - 찾는 법: 프로젝트를 머리말(`#load`)로 이은 컴파일에서 선언 심볼을 얻고, **모든 구문 트리**(불러온 파일 포함)의 이름마다
    `SemanticModel.GetSymbolInfo` 로 같은 심볼인지 본다. `SymbolFinder` 는 작업 공간의 문서만 뒤져 `#load` 한 파일을 못 본다.
  - 개수는 입력이 멈춘 뒤 분류와 같이 센다. 편집기 줄 사이에 끼우는 것은 AvalonEdit 의 줄 위 여백(VisualLine 높이)으로 한다.
- **목록은 GridControl**(오류 목록·Git 변경·기록·중단점), 트리는 GridControl + TreeListView(솔루션 탐색기).

## Git (VS 2026 의 Git 창 기준)

어댑터 규칙대로 `IGitAdapter` + 구현 + 팩터리. 구현 후보는 git.exe(VS 가 쓰는 것) 와 LibGit2Sharp - 단계 시작 때 잰다.

1. **상태 표시** - 솔루션 탐색기 줄 앞에 VS 의 원본 제어 표시(자물쇠=변경 없음·빨간 체크=수정·초록 +=추가·파란 +=추적 안 함).
2. **Git 변경 내용 창** - 커밋 메시지 칸, "스테이징된 변경 내용"·"변경 내용" 두 묶음 목록(GridControl), 줄마다 스테이지·스테이지 취소·변경 내용 실행 취소, "모두 커밋"(Ctrl+Enter).
3. **비교** - 변경 파일을 더블 클릭하면 비교 창(나란히·인라인), 편집기 여백에 바뀐 줄 색 띠(초록 추가·주황 수정 저장 전/초록 저장 후·빨강 삭제).
4. **기록·원격·브랜치** - Git 변경 내용 창 위의 가져오기·끌어오기·밀어넣기·동기화, 상태 표시줄 브랜치 누르면 전환·새 브랜치, "Git 리포지토리" 창의 기록 목록.

## 단계

1. **엔진** - 프로젝트 모델·읽기/쓰기, 여러 파일 컴파일, 파일별 오류, 리소스 API. 하네스(`--vision`)로 본다. ✅
2. **완성·분류** - 머리말 방식. ✅
3. **작업 공간 VM** - 프로젝트 열기·닫기, 트리 줄, 문서(탭), 저장·모두 저장, 파일·폴더 추가·이름 바꾸기·빼기, 실행·검사 연결. ✅
   (`ScriptProjectWorkspace` · `ScriptProjectNode` · `ScriptDocument` · `Helper/FileChangeWatcher`. 화면은 아직 옛 한 파일 편집기 -
   프로젝트를 열면 검사·실행은 프로젝트로 돌지만 탐색기·탭은 4단계에서 붙는다.)
4. **VS 2026 화면** - DockLayoutManager·메뉴·도구 모음·상태 표시줄·솔루션 탐색기·문서 탭·오류 목록. F9 중단점·Pause 비상 정지, Delete 휴지통·프로젝트에서 제외. `--views`.
   ✅ 첫 판(2026-09-13). `--script-screen` 으로 화면 밖에 띄워 바인딩 오류 0·PNG 확인. **앱에서 손으로 밟지는 않았다** - 도구 창 끌기·자동 숨김,
   배치 저장·복원, 탭 닫기 묻기, F2·Delete·끌어다 놓기, 오른쪽 메뉴, 오류 목록 더블 클릭은 앱에서 본다.
4b. **참조 표시(CodeLens)** - 참조 N개와 참조 창.
5. **플레이 화면** - 프로젝트 고르기.
6. **Git** - 위 네 가지 차례로.
