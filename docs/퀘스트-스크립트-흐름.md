# 퀘스트 스크립트 흐름 - 화면이 판단까지 오는 길

2026-09-26 하루에 쌓인 것을 한 장으로(사용자 "이거 나중에 분석할라면 힘들겠다"). 스크립트는 `D:\Minguk.Tools.프로젝트\아이온2\퀘스트\main.csx`(git 아님), 공용 사냥 기능은 `..\공용\사냥기능.csx`.

## 1. 화면이 스크립트에 오는 길

```
게임 창 ──WGC 30fps──▶ WgcCaptureSession ──▶ SharedCaptureHub ──▶ 화면(미리보기·검출·조준·녹화: 30fps 다 씀)
                          │ 리드백(CPU 픽셀)
                          └─▶ MaybePublishFrame: 0.1초에 한 장만 ──▶ PerceptionHub(FrameVersion +1)
                                                                        │
스크립트  읽기("자리") · 글줄들("자리") · 그림있나("본보기", 문턱, "자리")  ◀┘  같은 FrameVersion 이면 지난 결과(프레임 캐시)
```

- 30fps 는 미리보기·검출·조준·녹화가 쓴다. **스크립트의 OCR·본보기는 0.1초에 한 장**(8MB 복사를 솎음) - OCR 한 번이 20~400ms 라 그 이상은 못 쓴다.
- 읽기는 스크립트 스레드에서 **부를 때 동기로** 돈다. OCR 이 따로 계속 도는 게 아니다. `따로돌리기`(체력·줍기·물러나기)는 제 스레드에서 각자 읽는다.
- 프레임 캐시(`LiveScriptApi.FrameCached`): 같은 자리를 같은 프레임에 두 번 읽지 않는다. 본보기는 문턱과 무관하게 가장 닮은 자리를 캐시.
- **검은 프레임 5초 → 창 캡처를 스스로 다시 잡는다**(`WgcCaptureSession.WatchBlackFrame`) - 아이온2 지역 이동 로딩 뒤 검은 프레임만 오던 것.

## 2. 영역(regions.json)과 엔진

| 자리 | 엔진 · 배율 | 쓰는 곳 |
|---|---|---|

| 중앙안내 | PP-OCRv5 GPU · 1 | Alt+1 직후 「던전 진행 중에는 … 자동 이동을 할 수 없습니다」(y≈258, 「창」 밖) |
| 자막 | PP-OCRv5 GPU · 1 | HUD 없을 때 컷신 자막 → 한 번 클릭 + SKIP |
| 안내띠 | Windows · 2 | 「F 조작」·「F 대화」 - 물건 자리를 따라 움직여 넓은 띠(x 0.47~0.72, y 0.44~0.72) |
| 자동이동 · 체력 · 대상 · 줍기 · 지역 | Windows · 2 | 매 바퀴 읽는 작은 글. 빠르고 숫자·짧은 글은 그런대로 |
| 창 | Windows · 1 | 묻는 창·단추 글(y 320~940) |
| 대상줄 · 창닫기 · 스킵 · 대화표시 등 | (본보기 그림) | `Resources\*.png` - 다이아몬드 셋 · 확인/완료 단추 · X · SKIP · 「F ▼」 |

- **게임 해상도는 1920×1080** - 다 거기서 쟀다. 1920×1200 이면 HUD 가 밀려 전부 틀린다(모니터를 바꾸면 게임이 따라간다).
- 영역별 엔진·배율은 영역 패널 그리드(「OCR」·「확대」 열). Windows OCR 은 11~15px 한글을 「지체아기」(처치하기)처럼 틀려 판단용 한글은 PP-OCRv5.
- GPU 가 두 장이면 인식 도구 줄 「GPU」 콤보로 게임과 다른 카드(`DmlDevice.Index`). 다른 PC 에 그 번호가 없으면 0 으로 내려앉는다.

## 3. main.csx - 본 루프와 전략

```
while:
  이동중(자동 이동 글) · 맞는중 → 지나가는중이면 공격 멈춤 / 싸우기()(공용) / 맞는데 대상 없으면 Tab(0.25초)
  창정리()   본보기로 확인·완료 단추 F, 모노리스 공명→X, 전체 창 X, 메뉴 X, 안내 창 Esc, SKIP   (0.5초에 한 번, 두 번 봐야 누름)
  대화보임() → 대화하기()   X만화면닫기()
  퀘 = 퀘스트읽기()  (0.4초마다)      빈화면처리(로딩·컷신·검은 화면)   지역확인()   진전확인()
  처치단계 = 잡기중 ∨ (Tab 으로 다이아몬드 본 수집 단계)
  전략 = 전략들.First(맞나)  →  전략.돌기(퀘)
```

| 전략(위가 먼저) | 맞나 | 돌기 |
|---|---|---|
| 던전걷기 | 「자동 이동을 할 수 없습니다」 를 본 단계 | 안내 F → 처치면 Tab → 미니맵 표시(`퀘스트,목표`) 쪽 `길찾아걷기` 3초, 막히면 A·D·S+A·S+D 로 비켜, 8번이면 멈춤 |
| 공격 | 처치단계 | 점프 → Tab(0.6초 틈) → 4초 안 잡히면: 멀면 Alt+1 · 다 왔으면 미니맵 몹 쪽 걷기 |
| 조작 | 개수 있음 ∨ 대화·조사·싣기… | 안내 F(안 먹으면 2번 뒤 Alt+1 · 먹으면 5초 안 움직임) → 말풍선 F → 점프 → 수집이면 Tab 으로 다이아몬드 확인 → Alt+1 |
| 이동 | 그 밖 | 안내 F → 말풍선 F → 점프 → 자동 이동 중이면 기다림 → Alt+1 |

- `퀘스트누르기`: Alt+n → 0.8초 → 중앙안내·창 읽기(못 간다는 글이면 던전걷기로) → 묻는 창 F → 자동 이동 걸렸나 4×0.3초.
- `점프하기`: 100m 넘으면 제목 줄 옆 아이콘 → 확인 창 F. 30초에 한 번.
- 멈추는 조건(삑 두 번): **1분 진전 없음**(글 바뀜·개수 오름·거리 3m 줄어듦·F 먹음·몹 잡음이 진전) · 던전 8번 막힘 · 검은 화면 10초 · 게임 창이 앞에 없음.

## 5. 로그 보는 법

`Minguk.Tools\bin\...\Logs\<날짜>.log` - `스크립트 시작` 부터. `보기: 단계 =` 가 고른 전략, `호출: ... Key(` 가 실제 누른 키, `걷기 시작/막힘` 이 던전 걷기. 읽은 값은 `호출: ReadAt/ReadLines`.
길을 못 찾은 순간의 미니맵은 프로젝트 `진단\길찾기\`.
