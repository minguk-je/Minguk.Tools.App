# 자리 안 칸 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 이름 붙인 자리(`NamedRegion`) 안에 칸(`RegionCell`)을 두고, 칸마다 읽으며, 스크립트는 `자리.칸` 으로 부르고, 미리보기에서 칸을 별개 어도너로 편집한다.

**Architecture:** 칸은 자리 기준 0~1 좌표를 가진 자식 목록으로 `regions.json` 에 저장한다. 읽기는 순수 도우미(`RegionTargets`)가 자리/칸 → 화면 사각형 목록을 만들고, 화면·스크립트가 사각형마다 엔진을 부른다.
편집기는 `RegionItem`·`RegionCellItem` 이 공통 바탕(`RegionItemBase`)을 나눠 Thumb·어도너 흐름을 같이 쓴다.

**Tech Stack:** .NET 10 WPF · DevExpress 26.1 (`TreeListView` + `IChildNodesSelector`) · 실행형 하네스

**Spec:** `docs/superpowers/specs/2026-09-16-자리-칸-design.md`

## Global Constraints

- **칸은 돌린 직사각형**(사용자 2026-09-16): `RegionCell.Angle`(도, 시계 +), 상자 가운데 중심, 회전은 픽셀 공간. 읽을 때 감싸는 상자를 잘라 역회전으로 세운다(`RegionTargets.Bounds`·`Upright`), 허브 `TryGetFrameSize`.

- 화면 글은 한국어. 코드 이름에 `AdornerLayer`·`Adorner` 를 칸/자리 뜻으로 쓰지 않는다(WPF 형식과 겹침).
- 칸 좌표는 자리 기준 0~1, 소수 4자리로 반올림해 저장(자리 `Rect` 와 같다).
- 자리에는 칸이 늘 하나 이상. 옛 파일은 「칸1」(0,0,1,1)을 붙인다.
- 이름에 `.` 금지. 칸 이름은 자리 안에서 대소문자 무시로 유일.
- 목록·트리는 GridControl(`TreeListView`), 버튼은 BarManager 항목, 아이콘은 확인된 Axialis(`image:FreeImage`).
- 커밋은 사용자가 시킬 때만. 줄바꿈 LF, 기존 BOM 유지.
- XAML 을 고치면 `--views` 와 `--script-screen`.
